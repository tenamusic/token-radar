The model, stated in full 

implied value = TVL x category multiple
              x growth factor
              x vintage factor
              x reach factor
  • Category multiple — the median market-cap / TVL of this snapshot's own tokenised protocols in the same category (at least 2 peers, else the all-category median), clamped to 0.20–2.50.
  • Growth factor — 1 + clamp(7-day TVL change, −50%, +100%) × 0.60. Momentum is marked up, decline marked down, extremes capped.
  • Vintage factor — 0.80 + 0.45 × min(days live without a token, 1460) / 1460. Years at scale with no token means more accrued value to launch into. Unknown listing date counts as one year.
  • Reach factor — 1 + 0.03 × extra chains, up to +30%. Distribution supports a higher launch value.

One function scores every row from the snapshot's own fields; no protocol name is special-cased. Every row carries its four factors, and the detail view recomputes the multiplication in front of you.
